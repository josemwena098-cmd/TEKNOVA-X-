## 🚀 About TEKNOVA-X

TEKNOVA-X is a simple Android security-checking project
created for users who want to inspect downloaded files
and learn basic security analysis using Termux.

## ✨ Features

- 📱 Basic device information
- 🔎 Review selected downloaded files
- 🔐 Calculate SHA-256 file hashes
- 🖥️ Simple terminal menu
- ⚡ Lightweight Python application
- 📚 Beginner-friendly Termux project

## 📦 Installation

Install Git and Python:

```bash
pkg update
pkg install git python -y
```

Clone the repository:

```bash
git clone https://github.com/josemwena098-cmd/TEKNOVA-X-.git
```

Enter the project folder:

```bash
cd TEKNOVA-X-
```

Run TEKNOVA-X:

```bash
python teknova.py
```

## 🛠️ Storage Permission

If you want to inspect files in shared storage, run:

```bash
termux-setup-storage
```

Allow the permission when Android asks.

## 🎯 Usage

Open TEKNOVA-X and choose:

- `1` — Scan selected downloaded files
- `2` — Exit

The scanner displays SHA-256 hashes for selected file types.
A hash is an identifier, not proof that a file is malicious
or safe.

## ⚠️ Important Security Notice

TEKNOVA-X is a basic file-review tool, not a full antivirus.

It does not scan every application or verify the entire
Android system. A clean result does not guarantee that
your phone is malware-free.

Use Google Play Protect or a trusted mobile security tool
for broader protection.
